# Website Copy — everything written on the site

This document lists **every piece of text on the website**, where it appears, and what's needed for each one. The current wording is shown under each item — it's all placeholder, so feel free to rewrite anything (or keep what works).

**How to use this:** under each item, write your new wording next to **"New:"**. If you're happy with the current wording, just write "keep". Send the whole document back when you're done and everything will be updated on the site.
